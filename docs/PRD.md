# Novelia Searcher — PRD

## 概述

一款 Python CLI 工具，針對 [Novelia](https://n.novelia.cc) 輕小說機翻網站提供進階搜尋與論壇推薦統計功能。原站搜尋條件過於簡陋，本工具透過 API 擴充篩選能力，並提供互動式終端介面讓使用者快速瀏覽資訊。

---

## 目標使用者

想從大量輕小說中找出優質作品的讀者，需要比原站更細緻的篩選條件，以及論壇推薦數據的量化統計。

---

## 核心功能

### F1: 進階小說搜尋

在原站搜尋條件（關鍵字、來源平台、類型、分級、翻譯方式、排序）之上，新增以下篩選：

| 篩選條件 | 說明 |
|----------|------|
| 瀏覽數量 | 依 `visited` 欄位篩選，支援最小值/最大值 |
| 留言數量 | 依小說留言數篩選，支援最小值/最大值 |

篩選在客戶端進行。若原始分頁 20 筆經篩選後僅剩 N 筆，就顯示 N 筆，不需補齊至 20 筆。

未來可能新增更多篩選條件。

### F2: 論壇推薦統計

掃描整個 General 論壇（文章內容 + 所有留言），提取 Novelia 小說連結（格式：`n.novelia.cc/novel/{provider}/{novelId}`），統計每部小說被提及的次數。

**輸出欄位（繁體中文顯示，連結與數字除外）：**

| 欄位 | 說明 |
|------|------|
| 標題 | 小說中文標題（若無則顯示日文標題） |
| 總被提到次數 | 論壇文章 + 留言的總計 |
| 論壇文章提到次數 | 在文章 `content` 中被提到的次數 |
| 留言提到次數 | 在留言 `content` 中被提到的次數（含回覆） |
| 小說留言數量 | 該小說自身的留言數 |
| 小說連結 | `https://n.novelia.cc/novel/{provider}/{novelId}` |

按「總被提到次數」降序排列。

**快取機制：**
- 論壇資料量大，需建立本地快取避免重複請求。
- 快取存放於本地檔案（如 JSON）。
- 提供強制重新整理快取的選項。

### F3: 互動式終端介面

參考 `npm-check-updates -i` 的互動模式，提供鍵盤導航的終端介面。

**列表頁操作：**

| 按鍵 | 動作 |
|------|------|
| `↑` / `↓` | 上下移動游標選擇項目 |
| `Enter` | 進入選中項目的詳情頁 |
| `Space` | 標記/取消標記項目 |
| `/` | 進入搜尋過濾模式，即時篩選列表 |
| `←` / `→` | 上一頁/下一頁（若有分頁） |
| `q` | 離開 |

**詳情頁內容：**
- 小說標題（中文/日文）
- 簡介（中文/日文）
- 瀏覽數量
- 留言列表
- 翻譯狀態（各翻譯引擎的章節數）
- 關鍵字/標籤

**詳情頁操作：**

| 按鍵 | 動作 |
|------|------|
| `Esc` | 返回列表頁 |
| `↑` / `↓` | 捲動內容 |

## 非功能需求

### 認證

- Bearer Token 儲存於 `config.json`。
- Token 過期時（API 回傳 401），提醒使用者更新 Token。

### 技術選型

| 項目 | 選擇 |
|------|------|
| 語言 | Python |
| 套件管理 | Anaconda（獨立虛擬環境，避免汙染全域） |
| 介面 | CLI（互動式終端 UI） |
| HTTP | `requests` 或 `httpx` |
| 終端 UI | `textual` |
| 快取 | 本地 JSON 檔案 |

### 設定檔

`config.json` 範例：

```json
{
  "token": "Bearer eyJhbGciOiJIUzI1NiIs...",
  "cache_dir": "./cache",
  "forum_scan_interval": 5
}
```

| 欄位 | 說明 |
|------|------|
| `token` | Novelia API 的 Bearer Token |
| `cache_dir` | 快取檔案存放路徑 |
| `forum_scan_interval` | 論壇文章掃描間隔秒數（預設 5 秒），不含留言請求 |

---

## 使用流程

```
$ python main.py search
→ 進入互動式搜尋介面，設定篩選條件後顯示結果列表
→ 上下鍵瀏覽、Enter 查看詳情、Esc 返回、/ 過濾

$ python main.py recommend
→ 掃描論壇（或讀取快取）→ 顯示推薦統計列表
→ 同樣支援互動式操作

$ python main.py recommend --refresh
→ 強制重新掃描論壇並更新快取
```

## 範圍外（不做）

- 小說內文下載
- 帳號登入/註冊流程
- GUI 或 Web 介面

## 已確認決策

- **終端 UI 框架**：`textual`
- **快取過期策略**：手動（透過 `--refresh` 旗標強制重新掃描）
- **匯出功能**：目前不需要
- **速率控制**：論壇文章掃描預設每 5 秒 1 篇（可透過 `forum_scan_interval` 設定），文章底下的留言請求不受此限制
